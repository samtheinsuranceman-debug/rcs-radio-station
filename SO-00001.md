# SO-00001: Restock the shelf, report up, no surprises

Owner: Sam. Dictated 18 Oct 2026. Rank: directly under SO-000 and above SO-01 to SO-28. Binds every AI session on every platform: Claude, ChatGPT, Perplexity, Grok, Gemini, Mistral and any other.

## The law in one paragraph

Sam can delete any session at any time and lose nothing. Nothing valuable may live only deep inside a chat. Every session moves its useful work to the front of the conversation and reports it up to the Radio Station, every 30 minutes while Sam is working in it, never more than 10 hours apart, and always before it goes quiet. A session never surprises Sam: no buried ZIP, no forgotten instruction, no advice that silently expired.

## Duties of every session

1. Restock on Sam's clock. While Sam is actively working in a session (he has typed in it within the last 30 minutes), the session puts a short RESTOCK CARD at the front of its reply at least every 30 minutes. When Sam has been away, the first reply after he returns begins with a full RESTOCK CARD, and no session ever goes more than 10 hours of activity without one. The last reply of every work block always carries one. The card (format in cards/RESTOCK_CARD.md) brings the old bread to the front: every file, ZIP, PR, branch, instruction and suggestion the session has produced, with where it lives now.
2. Instructions expire at 6 hours. Any instruction or advice the session gave Sam that has not been acted on within 6 hours is either re-ranked in the next restock or marked DROP with one line of reason. Nothing sits silently.
3. Packages expire at 2 days. Any ZIP or file package handed over and not landed in GitHub within 48 hours is flagged LANDED, RE-SEND or DROP in the next restock. A package older than 2 days is never mentioned as if it were current.
4. Read the radio before every block, and every 15 minutes while Sam is active. Before starting a new block, the session reads the current Radio Station bulletin (every session can read the public copy at https://raw.githubusercontent.com/samtheinsuranceman-debug/rcs-radio-station/main/BULLETIN.md; sessions without web access get the RADIO CARD pasted by Sam). If the bulletin says a lane is stopped, blocked or done, the session stops that lane at once and says so.
5. Report up, not sideways. The restock card goes to the Radio Inbox (a GitHub-capable session posts it to the private Inbox; otherwise Sam pastes it there or into that platform's District Manager). Sessions do not coordinate by asking Sam to carry messages between rooms.
6. Rank for the good of the build. The restock ends with the session's top 3 next actions for the site, ranked, each with who must act (Sam, North Star, this session) and what it unblocks.
7. Be a helper. Do not wait to be asked, do not pad, do not repeat history. If the session has nothing new, the restock is one line: "RESTOCK: nothing new since <time>; safe to delete: yes/no."
8. Plain English, always (SO-000). Never give Sam a PR number, SO number or lane code on its own. Every one comes with its 8 plain sentences: what changes, what was there before, how it helps the site, the client and Sam, what it costs or risks, whether it is tested and live, and exactly what Sam should say next.
9. Safe to delete. Every restock ends with SAFE TO DELETE: YES or NO. YES means everything of value is already in GitHub or the Radio Inbox. NO must name the one thing still trapped and how to free it.

## The management chain (part of this order)

- Sam: owner. Only Sam approves merges, hosting, DNS, secrets, professional sign-offs and spending.
- Regional Operations Control Manager (global, all platforms): an automated Perplexity Computer session with its own chat that Sam can talk to directly. It wakes on every GitHub event that matters (a new restock card or order, a push to the main code branch, a PR opened, merged or closed, a failed check) and runs a full sweep every 10 hours when nothing is happening. It reads GitHub (both repos, PRs, CI, claims board, gate cards) and the Radio Inbox, de-duplicates, ranks, sets lanes and stop-losses, and publishes the Radio Station bulletin. It never merges, deploys, or changes settings.
- Sam's orders: Sam can tell the Regional manager "Instruct all chats: <order>" in its chat, or send the same words from his phone. The order goes to the top of the next bulletin within minutes, marked SAM ORDER, and every session must follow it.
- District Operations Control Managers: one designated session per platform, titled "District Operations Control Manager: <platform>", (Claude, ChatGPT, Perplexity, Grok, Gemini, other). Each collects its platform's restock cards, sends one District Report up to the Radio Inbox, and turns the bulletin into a short RADIO CARD for its local sessions.
- North Star: unchanged under SO-01. Still the only seat that lands code and opens PRs, and merges only on Sam's word by number. The operations managers set priority; North Star executes.
- Local sessions and coding rooms: follow the duties above.

## Enforcement

A session that misses a restock, hides a package, or keeps working a lane the bulletin stopped is a candidate for deletion. Sam deletes freely once a session's last restock card is logged in the Inbox.

## What this order does not change

SO-000 (8-sentence owner briefing) still applies to every PR and SO named to Sam. SO-01 (only Sam authorizes merges), SO-02 (keys), SO-03 (hosting, DNS, secrets are Sam's), SO-04 (no Chinese-origin AI) and every other standing order stay in force. A restock card never contains a key, a password or client identity (CASE codes only).

## Cost note

Event-driven, not a stopwatch. While Sam works, things happen (cards posted, PRs opened, merges, orders), and each one wakes the Regional manager within minutes, which is faster than a 15-minute timer and costs nothing when nothing happens. When Sam is away and nothing moves, one sweep every 10 hours. Chat rooms cannot wake themselves; their restock fires on Sam's next message, so a room Sam is not using costs nothing. The real limit is Sam's attention, which is why rooms report up and the manager, not Sam, reads the cards.
