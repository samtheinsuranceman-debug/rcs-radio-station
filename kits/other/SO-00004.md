# SO-00004: Five-minute operations, AI does what AI can, every cycle to Drive, and the K-code

Owner: Sam. Dictated 18 Oct 2026, 04:10 Eastern. Rank: directly under SO-00003. Binds every manager and every session on every platform.

## 1. Five minutes while Sam works

When Sam is back at work (any message from him in any room or manager chat, any comment, commit, card or Drive upload in the last 30 minutes), every manager is in ACTIVE MODE: it checks, rebalances, redistributes workloads and tasks, re-ranks priorities and automations, and communicates to all chats every 5 minutes. When Sam is away, managers drop to IDLE MODE: one pass per cycle, and a full sweep at least every 10 hours. On Perplexity the scheduler floor is 15 minutes, so in ACTIVE MODE each run makes up to three passes about 5 minutes apart inside the run. On other platforms, as fast as the platform permits.

## 2. AI does what AI can

Anything an AI can do is done by an AI, not by Sam. That includes downloading files, zipping and uploading them to Drive, carrying files and reports across platforms, opening and updating documents, and, inside a lane the bulletin names for it, retrieving and rotating keys. Sam does only what only Sam can do: spend money, sign legal and professional approvals, and say the merge word. Rules for keys: a key operation happens only in a named lane assigned to a room with the proper access (normally North Star), it is announced before and logged after in the private Inbox, the secret itself is never written in any chat, card, bulletin or public file, and a HOLD goes to Sam first if the rotation could break the live site. Managers rank and assign key work; they never hold keys themselves.

## 3. Every cycle's work goes to Drive and is reported

Whatever a session produces in a 5-minute increment that has lasting value is uploaded at once to the right Drive folder (the dated Parts Bin for build parts; the project's own folder for documents), zipped under 5 MB where it is code or many files, named <PLATFORM>_<session>_<nn>_<what>, with a 00_INDEX.md kept current. The session then tells its District manager (card or report) that it did so, with the Drive link. On the next cycle the manager tells the appropriate room to retrieve the file from Drive, install or integrate it, and what to build on top of it. Nothing of value waits in a chat for a human to move it.

## 4. The K-code for public channels

Private channels (the private Radio Station, the private Inbox, private manager chats) always use real numbers: PR 575 is PR 575. Public channels (the public bus, radio cards for rooms that cannot read private GitHub, any text pasted into another platform) never show a real PR, issue or merge number. They show a K-code: K followed by the real number multiplied by (2X − 1). The reader divides by (2X − 1) to recover the real number; if the division is not exact, the code is corrupt and the reader asks. X is private: Sam gives it to each platform's District manager by direct paste, never through the bus or a kit. Standing-order numbers (SO-00001 and so on) stay in the clear because the orders themselves are published. Commit hashes, file paths, Drive ids, CASE codes and keys are still stripped from public channels, not coded. This is obfuscation, not encryption: the real protection remains that the repositories are private.
